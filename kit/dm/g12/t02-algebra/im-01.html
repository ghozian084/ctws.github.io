🌡️ Lab 2: Server Room Tolerances (Inequalities)

🔗 Companion Tool for: Worksheet M3, Section 3 (Server Room Tolerance)

Adjust the optimal temperature ($a$) and the error tolerance limit ($b$). See how the inequality $|x - a| < b$ visually traps the acceptable temperatures, while $|x - a| > b$ defines the danger zones.

$|x - 20| < 3$
