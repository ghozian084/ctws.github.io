1. Basic Concept: Absolute Value

The modulus $|x|$ represents the absolute distance from zero. Distance is always positive.
$|x| = x$ if $x \ge 0$, and $|x| = -x$ if $x < 0$.
To solve $|ax + b| = c$, split it into two possibilities:
Positive Case: $ax + b = c$     Negative Case: $ax + b = -c$

2. Example Question and Solution

Question: Solve $|2x - 5| = 9$.

Solution:
Positive Case: $2x - 5 = 9 \implies 2x = 14 \implies x = 7$
Negative Case: $2x - 5 = -9 \implies 2x = -4 \implies x = -2$
Answer: $x = 7$ or $x = -2$.

1. Basic Concept: Graphing Absolute Value

The graph of $y = |ax + b|$ takes the straight line $y = ax + b$ and reflects any part below the x-axis upwards. This creates a 'V' shape.
Key Points:
1. x-intercept (Vertex): Set $ax + b = 0$.
2. y-intercept: Set $x = 0$.

2. Example Question and Solution

Question: Find the vertex and y-intercept of $y = |2x - 4|$.

Solution:
Vertex: $2x - 4 = 0 \implies 2x = 4 \implies x = 2$. Coordinate: $(2, 0)$.
y-intercept: $|2(0) - 4| = |-4| = 4$. Coordinate: $(0, 4)$.

1. Basic Concept: Inequality Logic

Less-THAND ($<$): Represents a trapped boundary.
$|x| < a \iff -a < x < a$
Great-OR ($>$): Represents escaped, outer bounds.
$|x| > a \iff x > a$ OR $x < -a$

2. Example Question and Solution

Question: Solve $|x - 2| < 4$.

Solution: Less than means "trapped inside".
$-4 < x - 2 < 4$
Add 2 to all three parts: $-2 < x < 6$.

1. Basic Concept: Long Division

Polynomial division works exactly like numerical long division.
Golden Rule: $P(x) = D(x)Q(x) + R(x)$
(Polynomial = Divisor $\times$ Quotient + Remainder)
Crucial: Always insert placeholders (like $+0x^2$) for any missing terms!

2. Example Question and Solution

Question: Divide $x^2 + 5x + 6$ by $x + 2$.

Solution:
$x(x) = x^2 \implies (x^2 + 5x) - (x^2 + 2x) = 3x$. Bring down 6.
$3(x) = 3x \implies (3x + 6) - (3x + 6) = 0$.
Quotient = $x + 3$, Remainder = 0.

1. Basic Concept: The Theorems

Remainder Theorem: When polynomial $P(x)$ is divided by $(ax - b)$, the remainder is EXACTLY $P(b/a)$.
Factor Theorem: A special case of the remainder theorem. If $P(b/a) = 0$, then $(ax - b)$ is a perfect factor!

2. Example Question and Solution

Question: Show that $(x - 2)$ is a factor of $x^2 - 4$.

Solution: Let $P(x) = x^2 - 4$. Evaluate $P(2)$.
$P(2) = (2)^2 - 4 = 4 - 4 = 0$. Since Remainder = 0, $(x-2)$ is a factor.

1. Basic Concept: Translating Reality to Algebra

Mathematical Modelling takes physical constraints and translates them into algebra. If a bridge anchors to the ground, its height/stress at that point is zero. In polynomial terms, those points are roots, and their corresponding brackets are factors.

2. Example Question and Solution

Context: A roof curve $y = x^2 + cx - 8$ hits the ground at $x = 2$. Find $c$.
Solution: Hits ground $\implies y=0$. Therefore $P(2) = 0$.
$(2)^2 + 2c - 8 = 0 \implies 2c - 4 = 0 \implies c = 2$.
