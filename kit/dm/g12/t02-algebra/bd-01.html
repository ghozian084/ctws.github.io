Meeting 1: The Modulus Function (Part 1)

Main Concept Absolute Value

  • Definition: $|x|$ is the "absolute distance from zero."
  • $|x| = x$ if $x \ge 0$
  • $|x| = -x$ if $x < 0$
  • Physical distance is always positive: $|a - b| = |b - a|$

Activity CNC Error Tolerance

Hook: "A steel rod must be exactly 50 cm. The machine has an error tolerance of 0.2 cm. How do we write this distance mathematically regardless of whether it's too long or too short?"

Task: Walk the giant masking tape number line. Measure the distance from 2 to 5, and 5 to 2.

Meeting 2: Graphing Modulus Functions (Part 1)

Main Concept Graphing $y = |f(x)|$

  • The modulus acts as a reflection across the x-axis for any negative y-values.
  • Steps: Find the x-intercept (the "bounce" vertex) and the y-intercept.
  • The graph will be a 'V' shape for linear functions.

Activity Laser Reflection Folding

Hook: "If I fire a laser beam at the x-axis, it bounces off perfectly like a mirror."

Task: Draw $y = x - 3$ on tracing paper. Fold it exactly along the x-axis. Trace the negative part onto the positive side to create the V-shape.

Meeting 3: Modulus Inequalities (Part 1)

Main Concept Inequality Logic

  • Less Than ($<$): "Trapped inside".
    $|x - a| < b \iff -b < x - a < b$.
  • Greater Than ($>$): "Escaped outside".
    $|x - a| > b \iff x - a > b$ OR $x - a < -b$.
  • For $|ax+b| < |cx+d|$, square both sides!

Activity Server Room Tolerances

Hook: "A server room is at $20^\circ\text{C}$. An alarm sounds if the temp fluctuates by more than $3^\circ\text{C}$."

Task: Write this as a strict inequality ($17 < T < 23$) and as a modulus inequality ($|T - 20| < 3$).

Meeting 4: Polynomial Division (Part 1)

Main Concept Long Division

  • Similar to numerical long division.
  • Golden Rule: $P(x) = D(x)Q(x) + R(x)$
    (Polynomial = Divisor $\times$ Quotient + Remainder).
  • Insert placeholders ($0x^2$) for missing terms!

Activity The Area Model Reborn

Hook: "If a box volume is $x^3 + 3x^2 - 4x - 12$ and height is $x-2$, what is the base area?"

Task: Use the Grid Method as a puzzle. What must go on the top header to make the inside boxes equal the volume?

Meeting 5: Quadratic Divisors (Part 1)

Main Concept Higher Degree Divisors

  • When dividing by a quadratic (Degree 2), the remainder can be linear (Degree 1): $R(x) = ax + b$.
  • Alternative Method: Equating Coefficients. Let $P(x) = (x^2+px+q)(x^2+cx+d) + (rx+s)$.

Activity Scaling Up Complexity

Hook: "What if the base area of our box is given as a quadratic? Can we still divide a degree-4 polynomial by it?"

Task: Attempt to set up the long division bracket for a degree-4 dividend and degree-2 divisor.

Meeting 6: The Factor Theorem (Part 1)

Main Concept Factor Theorem

  • If $P(c) = 0$, then $(x - c)$ is a factor of the polynomial.
  • General Form: If $P(b/a) = 0$, then $(ax - b)$ is a factor.
  • Used to fully factorise cubics without guessing all brackets.

Activity Discovery via Substitution

Hook: "Long division takes time. What if we just want to know IF something is a perfect factor?"

Task: Half the class divides $x^3 - x^2 - 4x + 4$ by $(x - 2)$. Half calculates $P(2)$. Both equal Zero!

Meeting 7: The Remainder Theorem (Part 1)

Main Concept Remainder Theorem

  • When polynomial $P(x)$ is divided by $(ax - b)$, the remainder is $P(b/a)$.
  • Proof: $P(x) = (ax - b)Q(x) + R$. Sub in $x = b/a$ to destroy $Q(x)$.
  • Used to solve simultaneous equations for unknown coefficients.

Activity Extending the Logic

Hook: "If $P(c) = 0$ means no remainder, what does it mean if $P(c) = 5$?"

Task: Calculate $P(1)$ for $x^2 + 2x + 4$. Then divide it by $(x - 1)$. Verify they both equal the remainder!
